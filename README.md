# Teste Java - Iniflex

Projeto em Java feito para o teste prático do processo seletivo da Iniflex.

## O que foi feito:
- Cadastro das pessoas e funcionários (usando a classe Funcionario que herda de Pessoa)
- Remoção do funcionário João
- Formatação das datas para dd/mm/aaaa e dos salários com vírgula/ponto
- Aumento de 10% no salário de todos
- Agrupamento dos funcionários por função em um Map
- Filtro de aniversariantes dos meses 10 e 12
- Cálculo do funcionário mais velho
- Lista em ordem alfabética
- Soma do total dos salários
- Cálculo de quantos salários mínimos cada um ganha
